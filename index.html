設定

☁️ 雲端同步（GitHub 私人儲存庫）

戰術會一直自動存在這台裝置。填好下面資料後，也會自動同步到你的私人 GitHub 儲存庫，iPad 和電腦就能讀到同一份。存取權杖只存在這台裝置的瀏覽器裡，不會寫進網站程式碼。

🧭 地圖方向

網站會依據進攻方／防守方重生點自動旋轉地圖。如果某張地圖方向不對，按這裡把它再轉 90°（會記住）。

📐 技能尺寸校準

技能範圍以「公尺」記錄，並依每張地圖的官方座標比例換算，所以不能在地圖上隨意縮放。目前內建數值都是未經驗證的估計值（待校準）。沒有範圍的技能也可以在這裡自己選形狀。可以用「測距」工具對照遊戲內實際距離再修正；修改過的會標記為「自訂」並一起同步。

🔄 遊戲資料

遊戲版本一更新，網站會自動重新下載地圖與特務資料。如果地圖看起來還是舊的，可以手動重新下載。

ℹ️ 關於

私人非商業用途的戰術白板。地圖、地名、特務與技能圖示來自社群維護的 valorant-api.com；VALORANT 為 Riot Games 的商標，本網站與 Riot Games 無關。
